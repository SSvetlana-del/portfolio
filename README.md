# Портфолио Светланы Смирновой

Подготовлено для GitHub Pages: https://ssvetlana-del.github.io/portfolio/

## Публикация

1. Загрузите содержимое этой папки в корень репозитория `SSvetlana-del/portfolio`.
2. Откройте Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main; folder: / (root). Нажмите Save.

Файл index.html должен находиться в корне репозитория, рядом с папками assets и cases.
Архив ZIP необходимо распаковать перед загрузкой. Сам ZIP загружать в репозиторий не нужно.

Сайт статический. Сборка и зависимости не требуются.
